## 1. ما تم تفعيله

محدّد الفترة الموجود أعلى لوحة المدير أصبح فعّالًا مع الخيارات المطلوبة:

| القيمة | الظاهر |
|---|---|
| `today` | اليوم |
| `week` | هذا الأسبوع |
| `month` | هذا الشهر (الافتراضي) |
| `last_month` | الشهر الماضي |
| `all` | كل الوقت |

- نفس موضع المحدّد وحجمه وتصميم Astra-glass.
- النقر يفتح الخيارات، والاختيار يحدّث النص الظاهر.
- لا إعادة تحميل كاملة للصفحة.

---

## 2. حدود الفترة والتوقيت

الخادم يستخدم توقيت الكويت (UTC+3، دون توقيت صيفي) لجميع الحدود:

- **اليوم:** بداية اليوم في الكويت (شامل) → بداية الغد (غير شامل).
- **هذا الأسبوع:** السبت 00:00 في الكويت → السبت التالي 00:00 (أسبوع السبت–الجمعة)، شامل البداية وغير شامل النهاية.
- **هذا الشهر:** أول الشهر 00:00 → أول الشهر التالي 00:00.
- **الشهر الماضي:** أول الشهر السابق → أول الشهر الحالي.
- **كل الوقت:** بلا حد أدنى أو أعلى.

تم اختبار الحدود بتوقيت ثابت:

```
الآن = 2026-11-05T20:30:00Z  (= 2026-11-05 23:30 الكويت)
اليوم       = 2026-11-04T21:00:00Z → 2026-11-05T21:00:00Z
هذا الأسبوع = 2026-10-30T21:00:00Z → 2026-11-06T21:00:00Z
هذا الشهر   = 2026-10-31T21:00:00Z → 2026-11-30T21:00:00Z
الشهر الماضي = 2026-09-30T21:00:00Z → 2026-10-31T21:00:00Z
```

## 3. الـ API

المسار الموجود أصبح:

```
GET /dashboard/manager?period=today|week|month|last_month|all
```

- Manager-only (`@Roles(Role.MANAGER)`).
- بدون `period` يستخدم `month`.
- قيمة غير صالحة ⇒ `400`.
- الموظف ⇒ `403`.

### البيانات المتأثرة بالفترة

- الصفقات: العدد، القيمة، المتوسط، العمولة.
- منحنى الصفقات.
- أفضل الموظفين (عملاء/عقارات/صفقات خلال الفترة).
- العملاء الجدد والملاك الجدد.
- المتابعات المكتملة.
- تنبيهات محاولات التكرار.
- آخر الأنشطة من `AuditLog`.

### القيم الحالية التي لا تتحول إلى لقطة تاريخية

هذه تبقى **إجماليًا حاليًا** ولا تتغير بتغير الفترة:

- إجمالي العقارات النشطة وتوزيع حالاتها الحالي.
- إجمالي العملاء.
- إجمالي الملاك الرسميين (`Contact` نوع OWNER).
- إجمالي الموظفين والحسابات النشطة.
- المتابعات المتأخرة الحالية.
- العقارات بانتظار الاعتماد الحالية.

تتغير فقط القيم الفرعية المرتبطة بتاريخ داخل الفترة (عملاء جدد / ملاك جدد / صفقات / متابعات مكتملة / محاولات تكرار / نشاط).

## 4. سلوك الواجهة

- `GlassSelect` أصبح Controlled بـ `value={period}` و`onChange`.
- عند تغيير الفترة:
  - يبدأ طلب جديد فورًا.
  - تبقى البطاقات والقيم السابقة معروضة أثناء التحميل (لا تفريغ ولا تغيير حجم).
  - يُستخدم `requestId` لإسقاط أي استجابة قديمة، فلا تستطيع استجابة فترة سابقة أن تكتب فوق فترة أحدث.
- المزامنة الحالية محفوظة:
  - Polling كل 20 ثانية أثناء ظهور الصفحة.
  - `focus` / `visibilitychange`.
  - إشارات تحديث العقارات والعملاء.
  - كلها تستخدم الفترة المحددة حاليًا.
- تحسين إضافي: إعادة إنشاء دالة التحميل عند تغيير الفترة لم تعد تُطلق طلبًا إضافيًا من إشارات قديمة؛ تُطلق فقط عند وصول إشارة جديدة فعلية.

### التحقق في المتصفح

- تغيير سريع بين اليوم → كل الوقت → الشهر الماضي → هذا الأسبوع → هذا الشهر:
  - النص النهائي: **هذا الشهر**.
  - بيانات النشاط النهائية تطابق الشهر (3 عناصر).
  - جميع الطلبات انتهت بنجاح، ولا أخطاء Console.
- اختيار **الشهر الماضي** ثم الانتظار 23 ثانية:
  - لم يحدث أي طلب لفترة أخرى.
  - الطلبات الجديدة كانت `?period=last_month` فقط (اختيار + Polling 20 ثانية).
  - النص بقي «الشهر الماضي».
- الخيارات الخمسة ظهرت بالنصوص المطلوبة، والمحدّد غير معطّل.
