## 1. المطلوب
إزالة زر **«تحديث»** نهائياً من صفحة المحذوفات المخصصة للمدير، مع الحفاظ على شريط البحث، والتحميل التلقائي عند فتح الصفحة وبعد عمليات الاستعادة/الحذف النهائي.

## 2. التغيير المنفَّذ
- الملف: `apps/frontend/features/manager-properties/components/manager-trash.tsx`
- أُزيل زر `<Button>تحديث</Button>` من شريط الأدوات بالكامل (سطح المكتب والجوال — نفس شجرة المكوّن).
- لم تُحذف أي دالة أو import لأن `load()` ما زالت مستخدمة في:
  - التحميل التلقائي عند فتح الصفحة (`useEffect`).
  - زر «إعادة المحاولة» في حالة الخطأ.
  - بعد نجاح الاستعادة والحذف النهائي.
- `Button` ما زال مستخدماً لأزرار الاستعادة/الحذف النهائي/إعادة المحاولة.
- لم تُحذف أي أنماط CSS: الزر كان يستخدم أنماط `Button` العامة، وشريط الأدوات يحتفظ بقاعدة `flex` و`flex-wrap` و`label { flex: 1 1 220px }`، لذا يتمدد شريط البحث بعرضه الطبيعي مع محاذاة RTL سليمة.

## 3. ما لم يتغيّر
- قائمة المحذوفات، البحث، الاستعادة، الحذف النهائي.
- صلاحيات المدير وحماية المسار.
- APIs الخلفية.
- مخطط قاعدة البيانات أو البيانات.
